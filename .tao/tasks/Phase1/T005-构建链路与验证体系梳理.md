## 接口规范

## 验收标准
1. 笔记清晰描述两条链路并含关键 BUILD target 名称与依赖关系：
   - RTL 生成链：Chisel Scala → `chisel_binary` 生成 SystemVerilog（如 `//hdl/chisel/src/coralnpu:core_mini_axi_cc_library` 产出 `CoreMiniAxi.sv`，`//hdl/chisel/src/coralnpu:rvv_core_mini_axi_cc_library` 产出 `RvvCoreMiniAxi.sv`）→ verilator_cc_library 模型 → C++ tb → 可执行 sim
   - 软件链：`coralnpu_v2_binary`（交叉编译 RISC-V）→ ELF（含 ITCM/DTCM 布局）→ 加载到 sim/FPGA
2. 列出 Cocotb、Verilator C++ sim、UVM（仅说明不执行）三套验证的入口 target 与运行命令
3. 说明 hermetic verilator、RISC-V 工具链、第三方依赖（opentitan/libsystemctlm-soc 等）从哪拉取、如何缓存
4. 用 `bazel query`（或等价）对至少 3 个关键 target 输出依赖关系作为证据，**query 命令与原始输出须原文留存到笔记**（附日期与 commit 号）
5. 笔记被 reviewer 抽查关键命令可复现

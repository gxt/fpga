## 验收标准
1. 自定义测试程序（如：RVV 向量加法 + 标量浮点 + TCM 回读，或自定义指令组合）经交叉编译得到 ELF
2. `core_mini_axi_sim --binary <自定义ELF>`（或对应 cocotb 运行方式）退出码 0，输出/回读结果与预期一致，**判定采用具体数值/位宽精度比对**（记录预期值与实测值，如按位精确 / 浮点误差 ≤ N ULP / 整数逐字一致）
3. 提供可复现命令（含 bazel 或直接工具链调用方式）与结果记录在 `.tao/knowledge/` 或主仓库 `sim/README.md`
4. 说明测试覆盖了哪些 ISA/模块特性，作为对 T004 架构理解的反向验证

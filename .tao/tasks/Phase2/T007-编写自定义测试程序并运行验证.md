# T007: 编写自定义测试程序并运行验证

## 执行环境
**执行环境**：本地

## 接口规范
- 输入：T003 已验证的 Verilator sim 环境；T004/T005 架构与构建链路理解；coralnpu `tests/cocotb/`、`tests/verilator_sim/` 现有测试写法（复用 `coralnpu_v2_binary` 宏、`.S`/`.cc` 编写范式）
- 输出：主仓库 `sim/` 下的自定义测试程序源码 + 运行脚本/说明；程序在 Verilator C++ sim（或等效 cocotb）上运行通过
- 约束：coralnpu/ 内文件零改动（若必须接入其 BUILD 体系，用主仓库脚本调用 bazel-bin 产物，或按 ADR-003 走 fork）；测试程序规模适中（单个或少量 ELF），聚焦验证理解而非复刻上游

## 验收标准
1. 自定义测试程序（如：RVV 向量加法 + 标量浮点 + TCM 回读，或自定义指令组合）经交叉编译得到 ELF
2. `core_mini_axi_sim --binary <自定义ELF>`（或对应 cocotb 运行方式）退出码 0，输出/回读结果与预期一致，**判定采用具体数值/位宽精度比对**（记录预期值与实测值，如按位精确 / 浮点误差 ≤ N ULP / 整数逐字一致）
3. 提供可复现命令（含 bazel 或直接工具链调用方式）与结果记录在 `.tao/knowledge/` 或主仓库 `sim/README.md`
4. 说明测试覆盖了哪些 ISA/模块特性，作为对 T004 架构理解的反向验证

## 1. 子卡整体结构

主板为 **S2C Dual Virtex-7 TAI Logic Module**，FPGA 标称 **F1/F2**（两片 XC7V2000T）。
本子卡为 **MPRC-V7FPGA CARD V1.2**（"Three V7-FPGA CARD"，原厂页标注 TOPSTAR/MPRC），
通过三个 Samtec QTH-120 连接器（DB1/DB2/DB3）分别插到主板 **J10 / J9 / J8** 上。

| 子卡功能块 | 主板连接器 | 子卡连接器 | 主要功能 |
|-----------|-----------|-----------|---------|
| **B1**（03~08 页） | **J10**（PCI） | DB1 | PCI 插槽、PCI 缓冲、PCI 时钟、PCI→USB 桥 |
| **B2**（09~14 页） | **J9**（BIOS） | DB2 | 以太网 PHY、双 SPI Flash 插座、x86 CPU ICE、PS2、VGA、I2C EEPROM、2 CPU JTAG |
| **B3**（15~21 页） | **J8**（EMMC/MMC） | DB3 | USB PHY + USB HUB、iNAND eMMC、TF 卡槽、UART0/1、CF 卡、IDE |

> 注意：J8 管脚表的偶数管脚（USB 信号）与奇数管脚（MMC/QIDE）分属 B3 子卡上不同功能，
> 但都通过同一 DB3→J8 连接器接入 F1。

## 2. J8（DB3，B3 块）— 当前工程主要使用

当前 RISC-V SoC 工程（UART、SD 卡、LED）全部经由 J8 接入。

### 2.1 USB（USB3318 + FE2.1 HUB）

| 芯片 | 型号 | 说明 |
|------|------|------|
| USB PHY | **USB3318**（SMSC/Microchip，QFN） | ULPI 接口，VDDIO 1.8V~3.3V，REFCLK **13MHz**，CLKOUT **60MHz**，VBAT 3.1~5.5V |
| USB HUB | **FE2.1**（Genesys Logic，LQFP48） | USB 2.0 4 端口 HUB，扩展出 2 个 USB 口 |

USB3318 的 13MHz 参考时钟来自板载晶振（13MHz-SMD4P-5032）。
ULPI 信号（DATA[7:0]/NXT/DIR/STP）经 J8 偶数管脚接到 FPGA F1：

| ULPI 信号 | J8 管脚 | FPGA1 引脚 |
|-----------|--------|-----------|
| USBD0 | 2 | AR36 |
| USBCLK | 4 | AR35 |
| USBD1 | 6 | AU37 |
| USBD2 | 8 | AU36 |
| USBD3 | 10 | AV37 |
| USBD4 | 12 | AV36 |
| USBD5 | 14 | BD41 |
| USBD6 | 16 | BD40 |
| USBD7 | 18 | BD39 |
| USBNXT | 20 | BC39 |
| USBDIR | 22 | AT40 |
| USBSTP | 24 | AT39 |

> 状态：**尚未接入 SoC**（原 Chipyard 设计清单列为待评估）。USB3318.pdf 见 `../04-子卡与外设芯片/USB3318.pdf`。

### 2.2 存储：iNAND eMMC + TF 卡槽

| 器件 | 型号 | 说明 |
|------|------|------|
| iNAND eMMC | **SanDisk SDIN5D2-4G**（BGA169） | 4GB，8-bit（MMC0），走 J8 奇数管脚 MMC0D[7:0]/CMD/CLK |
| TF 卡槽 | 4-bit（MMC1） | 当前 RISC-V 工程 SD 卡启动用，信号见下 |

当前工程使用的 **MMC1（TF 卡，4-bit）**：

| 信号 | J8 管脚 | FPGA 引脚 | IO |
|------|--------|-----------|-----|
| MMC1CLK | 55 | AT37 | LVCMOS18, IOB TRUE |
| MMC1CMD | 53 | AT38 | LVCMOS18, IOB TRUE |
| MMC1D0 | 45 | BA43 | LVCMOS18, IOB TRUE |
| MMC1D1 | 47 | AY43 | LVCMOS18, IOB TRUE |
| MMC1D2 | 49 | AW44 | LVCMOS18, IOB TRUE |
| MMC1D3 | 51 | AW43 | LVCMOS18, IOB TRUE |
| TFCD（card detect） | 21 | BA39 | LVCMOS18 |

> 说明：iNAND（MMC0）与 TF 卡（MMC1）是两套独立存储，iNAND 未接入当前 SoC。

### 2.3 UART（B3_UART I2C 页）

UART0/UART1 为 TTL 电平（经 1V8/5V 缓冲），由 J8 接入 F1：

| 信号 | J8 管脚 | FPGA 引脚 |
|------|--------|-----------|
| UART0 RX（UART0SIN） | 46 | AV42 |
| UART0 TX（UART0SOUT） | 48 | AU42 |
| UART1 RX（UART1SIN） | 52 | AT44 |
| UART1 TX（UART1SOUT） | 54 | AN38 |

> UART0 是当前 Linux 控制台（115200 8N1）。板级串口经 CH341 USB-UART
> （主板上的转换芯片，非子卡）在主机上呈现为 `/dev/ttyUSB2`。

### 2.4 其它（B3）

- **CF 卡槽**（16 页）：CompactFlash，走 IDE 总线
- **IDE 缓冲**（15 页）：QIDE* 信号（QIDED0-15、QIDEIOW/IDEIOR/...），在 J8 奇数管脚
- **I2C**（17 页）：板上 I2C 总线

## 3. J9（DB2，B2 块）— BIOS 子卡

### 3.1 以太网 PHY（当前工程使用）

| 芯片 | 型号 | 说明 |
|------|------|------|
| 100M 以太网 PHY | **KSZ8081MNXIA**（Microchip/Micrel，QFN32） | MII 接口，10/100 Mbps，VDDIO=1.8V，PHYAD[2:0]=**001**（地址 1） |

MII 信号（18 个）接 FPGA F1：

| 信号 | J9 管脚 | FPGA 引脚 | 方向 |
|------|--------|-----------|------|
| MACTXEN | 62 | AU27 | FPGA→PHY |
| MACTXD0 | 74 | BA25 | FPGA→PHY |
| MACTXD1 | 76 | AY25 | FPGA→PHY |
| MACTXD2 | 78 | BB27 | FPGA→PHY |
| MACTXD3 | 80 | BB26 | FPGA→PHY |
| MACTXCLKI | 100 | AR26 | PHY→FPGA（25MHz TXC） |
| MACRXCLKI | 63 | AT23 | PHY→FPGA（25MHz RXC） |
| MACRXDV | 82 | AU25 | PHY→FPGA |
| MACRXD0 | 77 | AT25 | PHY→FPGA |
| MACRXD1 | 79 | AR25 | PHY→FPGA |
| MACRXD2 | 81 | AY27 | PHY→FPGA |
| MACRXD3 | 83 | AY26 | PHY→FPGA |
| MACRXER | 66 | BC28 | PHY→FPGA |
| MACCRS | 72 | BA24 | PHY→FPGA |
| MACCOL | 70 | BB25 | PHY→FPGA |
| MACMDIO | 71 | AP23 | 双向 |
| MACMDC | 73 | AL23 | FPGA→PHY |
| PHY 复位（SYSRSTN/ERST_N） | 2 | BA18 | FPGA→PHY |

> PHY 关键特性（见 `KSZ8081MNX-RNB Data Sheet v1.0.pdf`）：
> - 仅 MII/RMII，**不支持 SGMII/RGMII/GMII**
> - PHY 中断引脚 INTRP **未引出到 FPGA**（项目里用常量 0 代替）
> - 复位：ERST_N 低电平 ≥500μs（warm reset），上电后供稳→释放 ≥10ms

### 3.2 双 SPI Flash 插座（B2_SPI EPROM 页）

J9 上有**两个 SPI Flash 插座**（标注"双BOIS SPI FLASH 插座"）：

- **X86 SPI**：3VSPICLK/3VSPIDI/3VSPIDO/3VSPICS0
- **Uni SPI**：3VUSPICLK/3VUSPIDI/3VUSPIDO/3VUSPICS0

SPI 信号接 FPGA：

| 信号 | J9 管脚 | FPGA 引脚 |
|------|--------|-----------|
| SPICLK | 86 | BA28 |
| SPIDI | 88 | BA27 |
| SPIDO | 90 | BA29 |
| SPICS | 92 | AY28 |
| USPICLK | 116 | AT27 |
| USPIDI | 118 | AR28 |
| USPIDO | 115 | AJ26 |
| USPICS0 | 117 | AK25 |

> 项目早期 Chipyard 方案使用的 **W25Q32FV**（4MB，1.8V，见 `w25q32fv_3v3.pdf`）即插在这种插座。
> 当前 JTAG Boot 主线**不依赖 SPI Flash**，直接由 JTAG 下载。

### 3.3 其它（B2）

| 功能 | 说明 |
|------|------|
| CPU ICE（ICE86*） | x86 CPU 在线调试接口（J9 奇数管脚：ICE86TMS/TDI/TDO/BGI/BGO/RST/TCK/UNITMS 等） |
| PS2 | 键盘（KBCLK/KBDATA）、鼠标（MSCLK/MSDATA），J9.97/99/95/93 |
| VGA | **CH7055A-BF（QFN40）** VGA 转码芯片，DE2R/G/B* 信号 |
| I2C MAC EEPROM | **AT24C02N**（1.8V，SOIC），I2CSCL1/SDA1（J9.104/106）、I2CSCL2/SDA2（J9.112/114） |
| 2 CPU JTAG | 双 CPU JTAG 接口 |
